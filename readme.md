# Sistema de Stock
CRUD simple hecho en PHP + MySQL para gestionar productos.

## Funcionalidades
- Listar productos
- Agregar productos
- Modificar productos
- Eliminar productos

## Cómo correrlo
1. Clonar el repo en `htdocs` de XAMPP.
2. Importar el archivo `productos.sql` en MySQL.
3. Iniciar Apache y MySQL desde XAMPP.
4. Abrir `http://localhost/stock`.
